## Status and build

The tested port combines this profile with the shared graphics-memory, movie and NFC fixes linked under [Found on this game](#found-on-this-game). These are separate prerequisite contributions.

Update 1.0.1 (`v1`) over the US base, title `0100AE00096EA000`, SDK 3.5.1, Koei Tecmo KTGL and NVN. Tested on a Mac mini M4 running macOS 27.0.1, using nxnative's standard Mac host and controls. Fresh setup, the complete unskipped opening movie, the first Legend battle, movement and attacks, pause, saving and reloading worked. A copied late save resumed Watchers of the Triforce with Link at level 191; movement, attack effects, pause, exiting the scenario and Gallery movie playback/skipping also worked. This is a bounded gameplay check, not a full-campaign result.

## Profile

- Four modules: main, runtime shader compiler subsdk0, movie library subsdk1 and sdk.
- The 4 GiB reservation, 256 MiB alias/stack regions and `0xCD500000` application pool accommodate the game's roughly 3.14 GiB heap. Its NPDM requests no system-resource region.
- The registered inventory contains 1,004 shader entries and 395 vertex/pixel pairs, generated by the upstream splitter from packaged shaders and runtime GLSLC captures. The tables contain identifiers, source locations, pairs and compute-layout metadata.
- The profile uses the standard SDK rewriter and does not require game-specific rewrite patches.

## Running

Use `scripts/build_ipa_from_nsp.py <NSP folder> -k <prod.keys> --platform mac-app` with the owned game/key files. The app uses the normal settings and controller assignment supplied by nxnative.

Stock Mac keyboard: WASD moves, arrows navigate, J=A, K=B, U=X, I=Y, Q/E=L/R, Z/C=ZL/ZR, F/G=stick presses, Return=Plus and Tab=Minus. At first setup choose the preferred difficulty and Warriors controls with A. At the title press A, then select Legend Mode. To skip its opening movie use Plus, Left, A. Plus continues when the loading screen is ready.

## Found on this game

- [Legacy graphics-memory result layout, PR #709](https://github.com/seedds/nxnative/pull/709): the older SDK's output record is 32 bytes; the modern 64-byte answer must not overwrite it.
- [SDK 3 movie construction, PR #710](https://github.com/seedds/nxnative/pull/710): the movie library uses the two-argument constructor and its older PCM16/NV12 format enum. The shared decoder implements that construction contract.
- [NFC availability, PR #711](https://github.com/seedds/nxnative/pull/711): the game initializes `nn::nfc` separately from `nn::nfp`. The host reports the NFC library initialized with its reader disabled, allowing the original unavailable message to return to the menu.

## Open

- Amiibo scanning is unavailable. The shared NFC hooks report it disabled; the original dialog opens, dismisses and reopens safely. Its Switch System Settings wording is unchanged.
- Movie checks cover 1280×720 NV12 output: the complete first Legend opening and a partially played, then skipped Water Temple gallery movie. Other movie dimensions and the game's use of PCM output have not been exercised; PCM enum handling has software fixture coverage.
- The included `smoke.tsv` uses a fresh save, accepts default difficulty and Warriors controls, and stops at Select Mode. The longer movie, battle and save checks above were separate checks outside that route.
- No iPhone/iPad, physical-controller or complete-campaign validation is claimed. Only the exact update/builds above are registered.

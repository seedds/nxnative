# Baten Kaitos Origins (`0100C07018CA6002`)

Program 2 of [Baten Kaitos I & II HD Remaster](../0100C07018CA6000/README.md), update 1.0.3. Its RomFS holds the Baten Kaitos II assets and its own Unity shader variants.

With the 1 GiB application pool, the Mac address-region check reached alias +2.22 GiB in the first 15 seconds of `nnMain`. The Mac run reached the first room and moved Sagi after the intro and name entry. See the collection note for the shared settings and build command.

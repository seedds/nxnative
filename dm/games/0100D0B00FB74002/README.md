# XCOM 2: War of the Chosen (`0100D0B00FB74002`)

Program 2 of [XCOM 2 Collection](../0100D0B00FB74000/README.md). It first ships in the collection's `v131072` update and reports display version 1.0.1. The update supplies all 5,317 files in its 9.8 GiB RomFS.

The offline shader reader matched all 137 keys requested by the initial Mac startup probe. With the compiled library, the Apple M6 rendered the main menu, the autosave notice and the difficulty selection. The collection note has the build, memory and play instructions.

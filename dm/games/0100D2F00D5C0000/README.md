# Nintendo Switch Sports (`0100D2F00D5C0000`)

Update 1.5.0 (v589824, SDK 13.3.4). Nintendo EPD's engine (sead, agl, gsys) with Havok, on NVN. The profile was generated by the NSP script from 1.5.0 and has its one build row; the base game alone is not registered.

Status: fully playable on the Mac with Joy-Con (L) and (R) over Bluetooth, gyro aiming included. Fully playable offline: all seven sports (Tennis, Bowling, Chambara, Volleyball, Badminton, Soccer, Golf) were played to the end, alone and in two-player local play with guest Miis, with no crash. Winning a Chambara match aborted the game until the play report fix below; a won match was replayed with the fix, with no crash. Tested on engine `ccd834e`, which predates the hid, save and Mii stand-in fixes this game also needed (they reached `main` through [Nintendo Switch Sports Resort](../04008E001F098000/README.md)); not tested yet on current `main`.

## What it needs

| Setting | Where | Why |
|---|---|---|
| `render_cond on` | [`game.tsv`](game.tsv) | the game wraps clears of its UI target in `SetRenderEnableConditional` (ser 1834 at boot). Unconditional, they ran after the UI draws: a black screen from the title on |
| font glyph cache height cut to 16384 (`main+0x238e5c`) | [`patches.py`](patches.py), build `2f6883e8…` | `nn::font::TextureCache::Initialize` (`main+0x238b74`) takes the cache size from its `InitializeArg`: 0x400 wide and 0x8000 high, a 1024x32768 R8 linear texture. That is past Metal's 2D limit ([A linear texture past Metal's 2D limit](../../../docs/reference/nvn-objects.md#a-linear-texture-past-metals-2d-limit)), so no text drew. The cut reads the height as 0x4000; the cache's own placement and UVs use that value (`[this+0x2c]`), so the glyphs fit in half the rows |

The rest of `game.tsv` is the NSP script's guess, unchanged: memory layout, modules, shader groups.

## Controllers

- One Joy-Con per player for most sports (supported styles `0x1a`: handheld, Joy-Con (L), Joy-Con (R)). Soccer asks for a pair per player (styles `0x6`: handheld, dual Joy-Con), as on the console: two players need four Joy-Con. With one pair connected, the game's "two players?" question opens the controller applet, which closes as canceled (`hid controller applet: 2 to 2 players wanted, 1 connected … (canceled)`), and the game asks again.
- Motion calibration ("place the Joy-Con on a flat surface") passes with the six-axis IC information ranges the host now gives.

## Found on this game

- [Play report upload status](../../../docs/reference/services.md#play-report-upload-status): `prepo::GetTransmissionStatus` after a won Chambara match aborted the game (Result 0xe15).
- [A linear texture past Metal's 2D limit](../../../docs/reference/nvn-objects.md#a-linear-texture-past-metals-2d-limit): the glyph cache aborted the process about 4.5 s in.
- Fixed on `main` since `ccd834e`, met here first on that engine: the six-axis passthrough, calibration and IC information hooks (`hle_hid.c`), a read-only mount of the game's own save (`hle_fs.c`), and a Mii model stand-in whose every part has a texture and a mesh (`hle_mii.c`; with an empty one the game aborted about 28 s in at `nvnTextureGetFlags(NULL)`, registering `MiiCharModelTexture`).
